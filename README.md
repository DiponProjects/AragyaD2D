## 📖 About The Project

**AragyaD2D** is a comprehensive healthcare platform that bridges the gap between patients, specialist doctors, and medicine vendors. Our mission is to make quality healthcare accessible, affordable, and convenient for everyone.

### ✨ Key Features

- 🩺 **Online Doctor Consultation** - Connect with verified specialists via video calls
- 💊 **Medicine Delivery** - Order prescribed medicines delivered to your doorstep
- 📋 **Digital Prescriptions** - Store and manage all your prescriptions securely
- 👨‍⚕️ **Multi-role Platform** - Separate interfaces for Patients, Doctors, and Vendors
- 🔐 **Secure Authentication** - Role-based access control for all users
- 📱 **Responsive Design** - Seamless experience across all devices
